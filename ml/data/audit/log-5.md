## Judgement calls

- weightLossKg = 0 when a note says 'no weight loss' or 'weight stable' (lung-en-012, lung-en-062, colorectal-en-100).
- priorCancer is present as null with evidence when a note says 'no prior cancer' (lung-fi-099, colorectal-en-058).
- A 2WW / urgent 2-week referral naming the site gives suspectedDiagnosis 'suspected <site> cancer' when no other diagnosis is written (lung-fi-054, lung-en-088, ovarian-en-035, ovarian-en-082, ovarian-en-107). When the note names a benign explanation ('possibly/maybe period related'), that is used instead (ovarian-en-012, ovarian-en-058).
- generalCondition from an earlier visit of the same episode is kept; from a pre-symptom or unrelated visit it becomes null.
- Test dates not written in the notes ('last week', reporting visit, ordered on X) are dropped; with ca125Done true and no date, ca125Date is null (ovarian-fi-014, ovarian-en-082, ovarian-fi-095).
- ironDeficiencyAnaemia is null unless anaemia/iron deficiency is written; a low Hb alone is not enough.
- A phone or remote consultation counts as a visit (lung-fi-018).
- rectalExamResult 'not_done' and pelvicUltrasoundResult 'not_done' are kept only when the note addresses the test; never mentioned -> null (colorectal-en-085, ovarian-en-058, ovarian-en-082, ovarian-en-107).
- Pending or only-requested tests are not in testsDone; 'no tests yet' gives testsDone [].
- Note durations were changed only when they contradicted the visit dates (e.g. 'a few weeks' at the first visit and '4 months' six weeks later). The smallest consistent figure was used, and the duration field follows the corrected note.
- menopausalStatus is derived from age only when clear (<=37 premenopausal, >=58 postmenopausal), with no evidence; age 48 and 52 without a statement -> null (ovarian-en-028, ovarian-fi-087).
- 'Perusterve' (basically healthy) gives otherIllnesses [] (ovarian-fi-087); 'Fit & well' alone does not (ovarian-en-035, ovarian-en-058).
- symptomDaysPerMonth: 'constant' -> 30 (ovarian-en-073); 'about two weeks a month' -> 14 (ovarian-ctrl-fi-003).
- colorectal-en-021: visit count 2. lung-ctrl-en-006: suspectedDiagnosis taken from the earlier note. colorectal-ctrl-fi-005: duration 0 (same-day onset). colorectal-ctrl-en-013: mebeverine kept as a current medicine. colorectal-en-085: abdominalMass false from 'Abno exam nil'. lung-fi-099: FIT 186 kept as written despite 'no blood in stool'.
