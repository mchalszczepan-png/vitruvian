## Conventions applied

- Required field not supported by the notes -> null; optional field not supported -> removed.
- chestXrayResult / pelvicUltrasoundResult / ca125Done / fitDone are null when the test is never mentioned (not_done/false only when a note says it was not done or only requested).
- Test dates, units and medicine doses that the notes do not state were removed; a required date (ca125Date) with no stated date is null.
- packYears only from explicit numbers. symptomVisitCount evidence only when a note states the count in words.
- Durations: stated duration (months x 4.35), or time since the first documented visit when that is longer and the stated figure is contradicted. Where the note's own figure contradicted an earlier note, the today-note was fixed (see NOTE FIX).
- gpQuestion is the GP's own request/action sentence, translated to English for Finnish notes.
