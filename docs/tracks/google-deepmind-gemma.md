# Junction 2026 – Google DeepMind: Gemma track

Source: hackjunction.app/participate/45/tech-challenges/47 (screenshot, 2026-11-13).

## The challenge

Awarded to the team that shows the most innovative and impactful use of Google's **Gemma open models**. Judges look for creative applications, strong technical execution, and solutions that show the potential of open AI models to solve real-world problems.

## Prize

€1,000 per team for the top 3 teams, no ranking between winners.

## How to access Gemma

- Featherless AI: hosted Gemma models through an API
- Modal: run Gemma on serverless GPUs
- Verda: cloud GPUs to deploy Gemma yourself
- Google AI Studio: try Gemma in the browser
- Hugging Face: download Gemma models
- Official Gemma documentation for setup
- Check the Junction Hackerpack for event credits and access instructions
