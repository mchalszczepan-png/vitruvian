# Junction 2026 – Google DeepMind: Gemini API track

Source: hackjunction.app/participate/45/tech-challenges/48 (screenshots, 2026-11-13).

## The challenge

Build something extraordinary with Google's **Gemini API**. Open innovation: no set problem or industry. Show a meaningful, innovative and technically impressive use of Gemini, and why Gemini matters to the solution.

## Insight

Go beyond "adding an LLM to an app". Use Gemini's capabilities to enable something genuinely new or clearly improve an existing solution.

The submission must explain:

1. What problem you solve and why it matters
2. How you integrated the Gemini API
3. What makes your use of Gemini innovative or technically impressive
4. Why Gemini is an important part of the solution

## Prizes

- 1st: €4,000 + $1,000 Google Cloud credits per team member
- 2nd: €2,000
- 3rd: €1,000

## Resources

- Google AI Studio: get an API key, try models
- Gemini API documentation and quickstart
- Gemini API credits for up to 400 teams; instructions given during the event. Keys are made in Google AI Studio.
- Only participants aged 18+.
- Support at the Google DeepMind booth; "Build with Google DeepMind" workshop on Friday.
